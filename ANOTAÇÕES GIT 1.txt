Git Bash: Terminal do git aonde podemos escrever comandos git 

Flags, são atributos dos comandos para executa-los com diferentes condições 
exemplo: GitStatus -b (-b é a flag)

///////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////

COMO CRIAR UM REPOSITÓRIO-- Aula 01
01-Digite o comando 'git init' dentro da pasta que será armazenado o repositório
>Isso criará uma pasta .git oculta no windows, é possivel acessalá em Exibir>mostar ocultos (canto superior da tela)
02-Digite o comando 'git status' para conferir se esstá tudo OK!

-No github
01-Acesse seu perfil>Repositories>New(botão verde)


///////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////

///////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////
ENVIANDO UM REPO PARA O GITHUB-- Aula 02

01-Você precisará de algum arquivo dentro do repositório local para inicializar o git  
>Adicionamos o arquivo teste.txt
02-Digite o comando 'git init' para iniciar
03-Digite o comando git add teste.txt para adicionar arquivos no git 
>git add <nome do arquivo> para adicionar arquivos em especifico
>git . para adicionar todos os arquivos locais

>COMMIT

01-Após adicionado o arquivo no git digite 'git commit -m "Hello Word"
>Flag -m - Comando para adicionar uma mensagem


>CIAR UMA BRANCH MAIN 

01-Digite o comando 'git branch -M Main'
>Cuidado com letras maiúsculas e minúsculas
>Ou git branch -M <Nome da branch>
>Esta será a mestra de todas, aonde o código correto do código estará depositado

>SINCRONIZAÇÃO DA BRANCH LOCAL COM A BRANCH REMOTA
01-Na página de criação de um repo no github, copie o código de origem do repo 
Ex: git remote add origin https://github.com/Tyago404/curso_git_1.git

>ENVIAR OS ARQUIVOS PARA BRANCH REMOTA
01-Digite no terminal o comando 'git push -u origin Main
>Enviando para a main da origem 
>Cuidado com letras maiúsculas e minúsculas

Verificando mudanças do projeto - Aula 03

01-Comando 'git status'
>Para verificar em qual branch você está, os arquivos que não foram mapeados e os arquivos que precisam ser comitados


>Untraked files
-Arquivos novos que não estão s
U- Untraked File

>Changes not staged for commit
-Arquivos foram alterados mas não foram comitados 
M- Modified File

///////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////
Adicionando arquivos ao projeto - Aula 04

01-Digite o comando 'git add teste.txt' para adicionar arquivos no git 
>git add <nome do arquivo> para adicionar arquivos em especifico
>>É necessário apontar o caminho do arquivo com ../../
>git . para adicionar todos os arquivos locais

Changes to be committed
>O arquivo está pronto para ser enviado para commit

///////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////

///////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////
Salvando alterações do projeto - Aula 05

01-Após adicionado o arquivo no git digite 'git commit -a -m "Enviando a funcionalidade X"
>Flag -m - Comando para adicionar uma mensagem
>Flag -a - Comando para indicar todos os arquivos


///////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////

///////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////
Enviando código ao repo remoto - Aula 06
01-Após todos os commits, digite 'git push' e todo seu código já está disponível remotamente
/////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////// 

///////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////
Recebendo as mudanças - Aula 07
01-Quando temos um arquivo remoto adicionado por outro dev, precisamos pegar a versão mais recente do código para trabalhar em cima.
>Digite o comando 'git pull', este comando irá trazer todos os novos arquivos que estão na branch remota para seu código local

02-É sempre bom verificar se está trabalhando na última versão, digite git pull para verificar isso.
>Already up to date. Significa que está tudo ok e todos os arquivos remotos estão na sua maquina local 

03-É possivel adicionar e alterar arquivos diretamente do github!

///////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////

///////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////
Clonando repositórios - Aula 08
01 - Normalmente quando você irá trabalhar pela primeira vez, é necessário resgatar os arquivos da branch remota para sua maquina local
>Vá no github e adquira a URL da branch, em seguida digite no seu terminal o comando 'git clone <url da branch> .'
>>Não se esqueça do '.' no final, indica clonar no diretório atual

///////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////

///////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////
Removendo arquivos do repo - Aula 09

01 - Se você quiser remover o arquivo tanto do mapeamento git quanto dos arquivos do projeto
>Utilize o comando 'git rm <nome-do-arquivo>'

02 - Mesmo se for remover um arquivo, é necessário commitar isso.. Para que os outros devs não acessem um arquivo excluido

///////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////


///////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////
Histórico de alterações - Aula 010

01 - Para verificar os commits ou histórico das modificações feitas
>Digite o código 'git log', retorna um histórico completo das modificações

///////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////

///////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////
 Renomeando arquivos - Aula 011

01 - As vezes fazemos git push com nome de arquivo errado ou na pasta errada, o comando git mv move e renomeia o arquivo no mapeamento e no local
>Digite o código 'git mv <nome-do-arquivo> <nome-novo-do-arquivo>'

02 - Desse modo será como um Ctrl+x, não se esqueça de apontar o caminho do arquivo utilizando barra inversa '\' 
> .\css\footerStyle.css



///////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////

///////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////
Desfazendo alterações - Aula 012
01 - Quando você faz alterações em um arquivo adquirido pela branch remota e faz muitas coisas erradas, vc pode restaurar este arquivo
da forma como está na branch main e começar novamente..
>Digite o comando 'git checkout <caminho-do-arquivo> não se esqueça que o git utilizar '\' barra inversa'
Ex: git checkout .\css\footer.css

02 - Algo como um Ctrl+z

///////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////

///////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////
Ignorando arquivos no projeto - Aula 013
01 - Para ignorar arquivos no commit que contem informações sensiveis, senhas etc... podemos adicionar o arquivo '.gitignore'
>Dentro deste arquivo você deve colocar o nome de todos os arquivos que serão ignorados pelo mapeamento do git e não serão enviados para a branch remota

02 -  Se você estiver trabalhando com uma pasta cheia de arquivos sensiveis vc pode colocar a pasta dentro de gitignore e usar '/*'
para ignorar todos os arquivos dentro da pasta 
Ex: (em gitignore)> node_modules/*

IMPORTANTE!
-Primeiro criar o nome do arquivo dentro de gitignore e depois criar o arquivo na pasta raiz do projeto

///////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////

///////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////
- Aula 014
-Geralmente quando já está trabalhando a um tempo em vários arquivos e tudo deu errado..
Ao invés de corrigir linha por linha, o melhor a se fazer é restaurar todos os arquivos desde o ultimo git push/pull
>Digite no terminal 'git reset --hard origin/main'


IMPORTANTE!
-Tudo o que você fez nesse commit atual será eliminado
