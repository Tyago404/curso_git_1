Criando e visualizando Branches - Aula 01

01 - Para visualizar todas as branches criadas e visualizar em qual você se situa
>Digite o código no terminal 'git branch'

02 - Para criar uma branch a partir da branch master ou da branch atual
>Digite o código no terminal 'git branch <nome-da-nova-branch>'

!IMPORTANTE
Nunca criamos uma branch em cima de outra que nós criamos para novas funcionalidades..
Sempre partimos da branch de construção main, ou em alguma branch que está 100% aprovada!
///////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////


///////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////
Deletando branches - Aula 02

01 - Para deletar uma branch você deve digitar no terminal
>git branch --delete <nome-da-branch>  ou você pode utilizar a flag '-d': git branch -d <nome-da-branch>

02 - Não é comum deletar branches, apenas em casos aonde foi criada uma branch com nome errado

Obs:Nome de branch sempre separado por '_' Nova_branch

Mudando de branch- Aula 03

01 - Para mudar de branch digite o código
>Git checkout <nome-da-branch>

02 - Utilizando a flag '-b' Você pode além de mudar de branch ainda criar uma nova ao mesmo tempo
>Git checkout -b "<nome-da-nova-branch>"


!IMPORTANTE SEMPRE FAÇA O COMMIT ANTES DE MUDAR DE BRANCH POIS SE VOCÊ ESTIVER TRABALHANDO EM UMA BRANCH E FIZER CHECKOUT PARA A MAIN
>A MAIN IRÁ MESCLAR AS ALTERAÇÕES 


!IMPORTANTE NÃO CRIE UMA NOVA BRANCH A PARTIR DE UMA BRANCH NÃO AUTORIZADA
SEMPRE CRIE UMA BRANCH NOVA A PARTIR DA MAIN PARA FAZER ALGUMA FUNCIONALIDADE NOVA


boas praticas
>Crie sua branch com a funcionalidade nova..>Volte para a branch Main>De um git pull para atualizar>Crie outra branch para uma nova funcionalidade

Unindo branches - Aula 04

01 - Para unir a funcionalidade da branch A para a Main
>Após dar o commit vá para a branch main com Checkout e em seguida digite o código 'git merge <Nome-da-branch-contendo-a-funcionalidade>'

02 - Sincronize com a branch main remota para finalizar a tarefa com 'git pull'
>Uma mensagem para saber se sua branch está atualizada com a branch remota: Your branch is up to date with 'origin/Main'.

03 - Caso sua branch esteja muito atrás da branch em produção, não seria legal mergear sua branch com a Main e sim ao contrario
>É possivel pegar a branch Main e mergear com sua branch para você continar trabalhando porém em uma branch atualizada

04 - Será muito dificil mergear com a MAIN, geralmente fazemos ao contrario mergear sua branch com a main não a main com sua branch

 Stash - Aula 05


01 - Stash é como se fosse uma lixeira, você joga seu código no lixo mas pode restaurar, ele joga no lixo desde o ultimo commit 

>Para jogar no lixo 'git stash'
>Para listar todos os commits que estão escondidos ou na lixeira 'git stash list'

02 - Cada stash vai ser numerado, aqui por exemplo temos o stash 0 e o 1
stash@{0}: WIP on teste_criacao: ce6f4ea Novo commit
stash@{1}: WIP on teste_criacao: 5701cb9 Funcionalidade executada
OBS: 0 sempre será o ultimo stash


03 - Para recuperar o stash digite no terminal 'git stash apply <numero-do-stash>'

BONUS: Com o comando git stash show -p<numero do stash>
>Você consegue ver via terminal o que foi jogado em stash


04 - Para limpar as stashs podemos limpar todas de uma vez ou apenas uma
>Para limpar apenas uma digite no terminal 'git stash drop <numero-da-stash>'
>Para limpar todas digite no terminal 'git stash clear' SÃO DEFINITIVOS CUIDADO

Tags - Aula 06

01 - Quando queremos criar marcos no desenvolvimento ou versões
>PRIMEIRO FAÇA O COMMIT DA SUA VERSÃO ATUAL
>Para criar uma tag utilizamos 'git tag -a <nome-da-tag> -m <mensagem da tag>'

02 - Para que utilizar tags? R: Para criar versões de funcionalidades, vc vai adicionar um form e a cada funcionalidade nova vc da uma tag ou uma versao
logo se você estiver na versão 3 e a versão 2 ficou melhor.. Vc manda para o repo a v2

>'-a' Para criar um nome a tag e '-m' para criar uma mensagme sobre ela 

02 - Para listar as tags basta digitar 'git tag'

03 - Para mostrar uma tag especifica digite 'git show <nome-da-tag>' mostra também os detalhes
>Aperte seta para baixo para mostrar os detalhes

04 - Para navegar entre tags digite 
> 'git checkout <nome-da-tag>'


ENVIANDO E COMPARTILHANDO TAGS

01 - Você pode ao invés de enviar as branch para outro dev.. Enviar a tag 
>O comando para enviar a tag é 'git push origin <nome-da-tag>'
>Para enviar todas as tags é 'git push origin --tags'

02 - Para que compartilhar tags?
>Se caso você esteja trabalhando na tag v2 e um dev solicita seu código para trabalhar em cima.. Você ao inves de mandar a v2 que você ainda está trabalhando
você pode mandar a v1 que já está pronta!
