Encontrando Branches - Aula 01

01 - Para ter a branch de algum outro dev de trabalho em sua maquina devemos utilizar o comando 'git fetch -a'
> flag '-a' para puxar todas as branches existentes remotas

02 - Quando você der git fetch e em seguida listar as branches com git branch ainda não irá aparecer na sua lista.. Porém se você 
digitar git checkout <nome-da-branch-do-outro-dev> você irá conseguir entrar na branch dele. 
>Após isso ela irá aparecer no seu git branch


OBS: Quando você criou um novo branch e ainda não mandou pro repo.. Se você der um git push
o terminal irá mandar vc adicionar essa branch pro repo e já te dará o comando
' git push --set-upstream origin Funcionalidade_A'

///////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////
 Recebendo atualizações na produção - Aula 02

  1-Primeiro verifique se há atualizações com 'git pull' na Master local sua 
  2-Crie sua branch aonde você irá realizar sua tarefa
  3-Após feito sua tarefa commite-a e de um 'git push' para enviar ao repo
  >Sua branch irá precisar do comando para ser pusheada

  4-Faça isso com outra funcinalidade em outro arquivo com outra branch

  5-Após isso vá para o repo de produção e entre na Main dele
  6-De git pull para verificar se há atualizações e provavelmente irá aparecer as duas branches criadas pelos 2 devemos
  7-Na main do arquivo de produção você irá dar o 'git merge <nome-da-branch-dos-devs> uma por vez'
  8-Você terá na main do arquivo de produção as branches dos devs unidas
